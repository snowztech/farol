Claude Code and Codex run in a terminal, so any terminal works. One agent in one tab is fine. The trouble starts at three or four: which one is waiting for you, which one is still working, and which one just changed the file another is editing?

That's the job a terminal for coding agents has to do. I build one of the options below, Farol, so take my pick with a grain of salt. I've tried to be fair to the others and linked their own pages for every claim.

What an agent terminal needs

  • A session per agent, with its status. Working, waiting for you, or done, visible without clicking through tabs.
  • Isolation. Two agents on the same folder overwrite each other. A git worktree per task gives each one its own copy of the repo on its own branch.
  • A way to know it's waiting. A notification, a badge, ideally your phone. An agent that waits ten minutes for a yes is ten minutes lost.
  • Review before shipping. You read every diff an agent writes. The closer the diff is to the terminal, the more you actually read it.
  • Speed. Agents print a lot. A terminal that stutters with ten sessions open gets in the way of all of the above.

Farol

Farol is a native macOS terminal made for running several agents at once. It's built on libghostty, the engine behind Ghostty, and reads your Ghostty config.

Press ⇧⌘N, describe a task and pick Claude Code or Codex. Farol creates a worktree on a new branch and starts the agent there with the task as its first prompt. A task can also start from a Jira ticket or a GitHub issue. The sidebar shows every session with a dot that says working, waiting or done, and the menu bar or the notch shows the same from any app.

When an agent is done, the review panel shows its changes as one diff. You commit, push and open a pull request from there. There's a git graph and a three-column conflict resolver too. And Farol for iPhone lets you answer an agent from your phone, end-to-end encrypted.

Good for: Mac users who want a fast terminal with everything for parallel agents built in, for free. Watch out: Apple silicon only, the iPhone app is still in beta, and there are no scheduled agents yet.

Paradev (formerly Superset)

Paradev, called Superset until its rename, is the most complete app here. Each task gets a worktree, a branch and terminals. It has a diff viewer, a browser for previewing your app, automations that start agents on a schedule or an event, remote access to another machine, cloud workspaces, and integrations with Slack and Linear. It's built on Electron.

The desktop app is free for local workspaces. Remote access, automations, Linear, Slack and the mobile app are on Pro, at $20 a month per user, and cloud workspaces start with Team. Its code is public under the Elastic License 2.0, which isn't an open source license.

Good for: teams that want automations, cloud workspaces or Linux. Watch out: the best parts are paid, and it's an Electron app rather than a native terminal. I wrote a detailed Farol vs Paradev comparison.

Conductor

Conductor is a Mac app for running Claude Code, Codex and Cursor agents in parallel, each in an isolated workspace, then reviewing and merging their work. It's built around that workflow more than around a terminal.

Good for: people who want an app that manages agents for them, rather than a terminal. Watch out: its site doesn't say much about pricing or license, so check before you settle on it.

cmux

cmux is the closest to Farol in spirit: a native macOS terminal on libghostty, with vertical tabs, notification rings when an agent needs you, and a browser you can split next to the terminal and script. Its README calls it "a primitive, not a solution". It's GPL-3.0 and has an iOS app in beta.

Good for: people who want a fast terminal with agent notifications and prefer to build the rest themselves. Watch out: worktrees, review and pull requests are left to you.

Warp

Warp now describes itself as an agentic development platform. It has its own terminal, which it says is open source, its own coding agent, and it works with Claude Code and Codex too. It runs on macOS, Linux and Windows, and its agent runs are priced by usage.

Good for: people who want one vendor's agent and terminal together, or need Windows. Watch out: it's built around its own agent and cloud runs, which you may not need if you're set on Claude Code or Codex.

Ghostty or iTerm2, with tmux

The classic setup: a great terminal, tmux for sessions, and git worktree add by hand for each agent. Ghostty is fast and native, iTerm2 is mature and does everything. Neither knows what an agent is, so status, notifications and review are up to you, through hooks and scripts.

Good for: people who already have a setup they love and run one or two agents. Watch out: past three agents, the bookkeeping is yours.

How to choose

  • You're on a Mac and want everything built in, free: Farol.
  • You need Linux, cloud workspaces or scheduled agents: Paradev.
  • You want a fast terminal with notifications and will script the rest: cmux, or Ghostty with tmux.
  • You need Windows: Warp.

Whichever you pick, use a worktree per agent. It's the one habit that makes running agents in parallel work at all.
