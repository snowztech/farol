Farol and cmux are close cousins. Both are native macOS apps built on libghostty, the engine behind Ghostty, both read your Ghostty config, both are open source, and both are made for running Claude Code, Codex and other agents side by side.

Where they split is how much they do for you. cmux's README calls it "a primitive, not a solution": a fast terminal with notifications, a scriptable browser and an API, and you build the workflow. Farol builds the workflow in: a worktree per task, review, pull requests and a phone app.

I make Farol, so weigh what follows with that in mind. Every claim about cmux links to its own site or README, and the page says where cmux is the better choice.

The short version

  • Pick Farol if you want each agent in its own worktree, its diff reviewed and sent back as notes, and a pull request opened, all in one window, plus a phone app that costs nothing.
  • Pick cmux if you're on an Intel Mac, want a browser next to your terminal that agents can drive, or like building your own workflow on a CLI and socket API.

Where Farol is ahead

A worktree per task, built in

Press ⇧⌘N, describe the task and pick an agent. Farol fetches the default branch, creates a worktree on a new branch and starts the agent there. A committed .farol/setup prepares each new worktree, and a task can span several repos. In cmux, as in any terminal, you'd run git worktree add yourself. I wrote up how that works by hand.

Review that talks back to the agent

When an agent is done, the review panel shows its changes as one diff. Leave notes on lines and send them all to the agent in one message, or commit, push and open the pull request from there. A git graph and a three-column conflict resolver sit next to it. cmux has a diff viewer and shows a workspace's linked PR, but its site doesn't describe opening a PR from the app.

Tasks that start themselves

A task can wait for later: once at a set time, or again on the days you pick, each run in a fresh worktree. Each one is a Markdown file in ~/.farol/schedules/, so an agent can write one too. cmux's Task Manager is a resource monitor, not a scheduler.

The phone app is free

Both have an iPhone app. Farol's is free and on the App Store, and its messages go through a relay that can't read them. How the encryption works. cmux's iOS app comes with Pro, at $50 a month.

Where cmux is ahead

  • Intel Macs. cmux runs on Apple silicon and Intel. Farol needs Apple silicon.
  • A browser in the terminal. Split one next to your panes, and agents can navigate it, read the page, click and type. Farol opens your ports in your own browser.
  • A socket API. Every action is available through the cmux CLI and a Unix socket, which suits people who script their own setup.
  • More agents named out of the box, like Gemini CLI, Aider and Amp, with notifications from escape sequences, a CLI command or hooks. Farol connects four agents in one click and takes any other through farol status.
  • Cloud VMs on its paid plans, so agents can run off your Mac. Farol runs agents on your Mac or on a server of your own.

Which one to pick

If you want the whole loop in one place, from a task to a reviewed pull request, and your phone in the loop for free, try Farol. If you'd rather have a fast, scriptable terminal and wire up worktrees and review yourself, or you're on an Intel Mac, cmux is a great base.

Both are free on the Mac, and both read the same Ghostty config, so trying one costs you a download.

Moving from cmux to Farol

Install Farol from the download or with Homebrew:

  • Your Ghostty config, themes and fonts carry over. Farol reads the same file.
  • Connect your agents in Settings → Agents, one click each.
  • Press ⇧⌘N, describe the task and pick an agent. Farol creates the worktree and starts the agent on it.
  • For a machine you used with cmux ssh, add it as a server in the sidebar. Farol sets it up over ssh.

Questions

Are Farol and cmux forks of Ghostty?

No. Both use libghostty, Ghostty's terminal engine, as a library, and build their own app around it. cmux's FAQ says the same of itself.

Are both open source?

Yes. Farol is MIT licensed, and cmux is GPL licensed. Both Mac apps are free.

Does Farol run on an Intel Mac?

No. Farol needs Apple silicon and macOS 14 or later. cmux runs on Intel Macs too.

Can I use Claude Code and Codex at the same time?

Yes, in both. In Farol, each task picks its agent, and the sidebar shows which one is working, waiting or done.
